Kebijakan Privasi Duitku

Terakhir diperbarui: 16 November 2026.

Data apa yang disimpan?

Data keuangan yang kamu isi (transaksi, rekening, investasi, goal, anggaran, tabungan) disimpan di dalam HP-mu. Kami tidak punya server dan tidak menerima data itu.

Backup ke Google Sheets (opsional)

Kalau kamu mengisi Link dan Kunci skrip Google Apps Script milikmu di menu Profil, aplikasi mengirim salinan datamu ke Google Sheet milikmu sendiri lewat skrip itu. Data dikirim langsung dari HP-mu ke Google (alamat script.google.com), tidak lewat server kami. Aplikasi juga bisa meminta harga emas, kripto, dan saham melalui skrip yang sama.

Backup ke file (opsional)

Tombol "Simpan backup" membuat file di HP-mu yang kamu kirim sendiri ke tempat pilihanmu (misalnya Google Drive atau WhatsApp).

Akun di aplikasi

Username dan password dibuat di HP-mu dan hanya tersimpan di HP (password disimpan dalam bentuk hash, bukan teks asli).

Yang tidak kami lakukan

Tidak ada iklan, pelacak, analitik, atau penjualan data. Kami tidak membaca emailmu, kontakmu, atau file Drive lainnya.

Menghapus data

Hapus aplikasi untuk menghapus data di HP. Untuk menghapus backup, hapus file "Duitku Backup" di Google Drive-mu atau hapus skrip dan Sheet yang kamu buat.
