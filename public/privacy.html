Kebijakan Privasi Duitku

Terakhir diperbarui: 16 November 2026.

Data apa yang disimpan?

Data keuangan yang kamu isi (transaksi, rekening, investasi, goal, anggaran, tabungan) disimpan di dalam HP-mu. Kami tidak punya server dan tidak menerima data itu.

Backup ke Google Sheets (opsional)

Kalau kamu memilih "Masuk dengan Google", aplikasi membuat satu spreadsheet bernama "Duitku Backup" di Google Drive-mu dan menyalin datamu ke sana. Aplikasi hanya meminta izin drive.file, jadi hanya bisa membuka file yang dibuatnya sendiri, bukan file Drive lain. Data dikirim langsung dari HP-mu ke Google, tidak lewat server kami.

Yang tidak kami lakukan

Tidak ada iklan, pelacak, analitik, atau penjualan data. Kami tidak membaca emailmu, kontakmu, atau file Drive lainnya.

Menghapus data

Hapus aplikasi untuk menghapus data di HP. Untuk menghapus backup, hapus file "Duitku Backup" di Google Drive-mu atau cabut akses di myaccount.google.com/permissions.
